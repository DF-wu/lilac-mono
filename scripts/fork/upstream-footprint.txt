# Upstream footprint allowlist.
#
# Every upstream-owned file this fork modifies, with the reason it cannot live
# in a fork-owned module. `bun run fork:footprint` fails when a file outside
# this list differs from the merge base with upstream, and reports entries that
# no longer differ so they can be removed. Format: `<path>  # <reason>`.
#
# Keep entries to thin seams: imports, one-line registrations, closed-union
# members, and re-exports. Behavior belongs in fork-owned modules
# (`apps/core/src/surface/telegram/`, `apps/core/src/tool-server/tools/generate-image/`,
# `packages/utils/core-config/{telegram-surface,generate-image}.ts`, ...).
